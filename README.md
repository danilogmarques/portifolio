# Portfólio

Landing page pessoal criada com Next.js, TypeScript e Tailwind CSS.

## Começar

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no navegador.

## Personalizar

- Em `src/app/page.tsx`, substitua “Seu Nome”, a apresentação, as tecnologias e o e-mail.
- A lista `projects` no início de `src/app/page.tsx` contém os cartões do portfólio. Edite os títulos, descrições e tecnologias; preencha `url` com o endereço do projeto para exibir o link.
- Em `src/app/layout.tsx`, ajuste o título e a descrição usados nos resultados de busca e compartilhamentos.
